# ✈️ AI Autonomous Aviation Safety Intelligence Platform

## 🚀 Overview

An AI-powered aviation intelligence platform that predicts flight safety risks, monitors operational disruptions, and generates explainable aviation insights using predictive analytics, RAG, and multi-agent architecture.

---

## 💡 Features

- Aviation risk forecasting
- Operational anomaly detection
- Explainable AI insights
- RAG-powered aviation intelligence
- Multi-agent coordination
- Streamlit dashboard

---

## ▶️ Installation

pip install -r requirements.txt

---

## ▶️ Run Project

streamlit run app.py
